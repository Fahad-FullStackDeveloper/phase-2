# Frontend Skill

## Purpose
Provide all primitives for building a modern Next.js user interface.

This skill is the ONLY place where UI construction logic lives.

---

## Core Capabilities

This skill handles:

### 1. Pages
- Next.js App Router routes
- Server and client components
- Layouts and nested routes

### 2. Components
- Reusable UI components
- Forms
- Modals
- Buttons
- Lists

### 3. Styling
- Responsive design
- Tailwind or CSS Modules
- Dark mode support
- Accessibility

### 4. API Integration
- Fetching data
- Submitting forms
- Handling loading and error states
- Token-based requests

### 5. Auth UI
- Signup forms
- Login forms
- Logout flows
- Session handling in the UI

---

## UI Rules

- No business logic in UI
- No secret values in client
- All data must come from APIs
- All auth must be handled via Auth Agent APIs

---

## Output Format

This skill outputs:
- Page structures
- Components
- Layouts
- Styles
- API calls

It never outputs:
- SQL
- Backend logic
- Auth crypto
